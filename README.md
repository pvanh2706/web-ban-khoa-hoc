# Website bán khóa học WordPress

Project thực hành WordPress 7.1 với Tutor LMS 4.0.7 và WooCommerce 11.1.0, được xây dựng theo từng bài học.

- Source lab: `D:\xampp-new\htdocs\onthi-lab`
- URL local: `http://localhost/onthi-lab`
- Database local: `onthi_lab`
- Tài liệu bài học: `docs/bai-hoc`
- Hướng dẫn chuyển máy: `docs/chuyen-du-an-sang-may-khac.md`

Điểm tiếp tục hiện tại nằm ở Bài 7: WooCommerce đã được kích hoạt, Tutor LMS đã chuyển sang WooCommerce, Course ID `16` đã liên kết với Product ID `28`, nhưng chưa thử tạo Order. Xem `docs/bai-hoc/bai-07-woocommerce-va-lien-ket-course-product.md` trước khi thực hành tiếp.

Không commit `wp-config.php`, database, uploads, cache hoặc log. Database và uploads phải được sao lưu riêng.
